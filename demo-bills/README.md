# Demo bills for Add Expense OCR

Upload these in PI → Add Expense. OCR uses the **file name**:

| File | What it fills |
|------|----------------|
| `travel.pdf` | MakeMyTrip travel ₹48,200 |
| `consumable.pdf` | Sigma consumables |
| `duplicate.pdf` | Same invoice as EXP-1042 → GFR NON_COMPLIANT |
| `equipment.pdf` | New Thermo Fisher equipment bill |

Also served at: http://localhost:3000/demo-bills/travel.pdf

Or click the download links inside the Add Expense modal.

Without a file, use **Run OCR without file**.
